## 🚀 Proyecto destacado

### 💰 Finlia

**En construcción 🚧**

Finlia es una plataforma de **gestión financiera personal** enfocada en ayudar a las personas a comprender, organizar y mejorar sus finanzas.

El proyecto está siendo diseñado con un **núcleo de código abierto**, manteniendo una arquitectura flexible que permita incorporar en el futuro servicios comerciales e integraciones.

Estoy desarrollando Finlia como un proyecto para explorar diferentes áreas de ingeniería y tecnología:

* Arquitectura de software
* Datos financieros
* Análisis de datos
* Funcionalidades basadas en IA
* Agentes basados en LLMs
* Arquitecturas SaaS
* Desarrollo de código abierto
